# Archivos históricos

Esta carpeta contiene material del proyecto académico original que se conserva por valor histórico, pero que **no forma parte del runtime de la versión restaurada**.

## `database/`

Contiene los artefactos de SQL Server encontrados en la raíz del repositorio:

- `SistemaBiblioteca.mdf`
- `SistemaBiblioteca_log.ldf`
- `SQLQuery2.sql`

La aplicación Java Swing restaurada no utiliza actualmente una conexión JDBC activa hacia estos archivos. Se mantienen como evidencia del trabajo académico y de intentos originales de persistencia.

## `assets-original/`

Contiene recursos gráficos originales encontrados en `interfaces/fotis/` que no son necesarios para ejecutar la versión actual, pero forman parte del material histórico recuperado.
